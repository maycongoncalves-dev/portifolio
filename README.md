# Site completo da KRYTHOS

Este pacote contém a versão completa do site institucional da KRYTHOS e as quatro prévias autorais.
Não há etapa de compilação: o projeto usa HTML, CSS e JavaScript puros.

## Como abrir

Abra o arquivo index.html no navegador. Para desenvolvimento, também é possível usar a extensão Live Server do VS Code.

## Estrutura principal

- index.html: página principal da KRYTHOS
- css/reset.css: normalização dos elementos
- css/style.css: identidade visual e componentes
- css/responsivo.css: ajustes para tablets e celulares
- js/script.js: animações, navegação e interações
- assets/images: imagens, símbolos e arquivos sociais
- assets/fonts: tipografias locais e licenças
- assets/vendor: arquivos locais do GSAP usados na abertura
- previas: projetos autorais organizados de forma independente

## Prévias incluídas

- previas/vertice-cast: site institucional de três páginas (index.html, sobre.html e episodios.html)
- previas/impulso: site de treinamento online com área da aluna e painel demonstrativo
- previas/casa-aurora: site institucional de centro terapêutico feminino
- previas/pista-12: site de bowling, sports bar, eventos e pré-reserva

Cada prévia possui sua própria estrutura css, js e assets, seguindo o mesmo padrão do site principal.

## Observações

- As marcas e os dados das prévias são fictícios.
- Os formulários das prévias apenas simulam o envio.
- Os links comerciais da KRYTHOS apontam para o WhatsApp configurado no site atual.
- Mantenha os arquivos de assets/vendor para preservar a animação inicial da marca.
